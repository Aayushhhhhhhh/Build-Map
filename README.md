# BuildMap

A map-first real-estate discovery platform for Pune.

> Don't just search for a property. Explore where the city is being built.

## MVP
- Minimal, classy map-first UI
- Residential, commercial and mixed-use developments
- Upcoming, under-construction, ready and completed projects
- Project detail pages with construction progress and inventory
- Source/verification labels for trust

## Planned stack
Next.js + TypeScript · Supabase/PostgreSQL · Mapbox · Vercel

Current project phase: build the first polished UI with sample data, then connect verified project data.
